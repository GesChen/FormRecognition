# XLSX Mapping Auto-Generation Example

This folder is used by the XLSX mapping auto-generator as a convention example only.
It contains a 2025 `6pre` mapping, matching PaddleOCR template text for both sides,
and a copied 2025 blank data-entry workbook so the generator can compare mapping rows
to the corresponding workbook sheet structure.

The prompt explicitly forbids copying this example blindly; target ROI schemas,
target PaddleOCR data, and the target workbook structure remain the source of truth.
